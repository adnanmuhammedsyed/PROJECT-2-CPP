# PROJECT-2-CPP

## Student Management System

### Project Description
A C++ mini project designed to manage student information and results using Object-Oriented Programming.

### Features
- Store student roll number, name and marks
- Use private data members
- Parameterized constructor
- Getters and setters
- Marks validation (0–100)
- Display student details
- Calculate PASS or FAIL results
- Array of student objects
- Re-evaluation of student marks

### Language
C++
